# Pricing E-commerce – Estimation de l’élasticité prix

## Objectif
Estimer la relation entre prix et demande pour un produit e-commerce et analyser l’impact du prix sur le revenu.

## Méthodologie
- Nettoyage des données (transactions valides, filtrage par pays)
- Sélection d’un produit avec variation de prix suffisante
- Estimation d’un modèle de demande à élasticité constante
- Analyse du revenu

## Résultats
- Élasticité estimée : ~2.07
- Demande fortement élastique
- Stratégie recommandée : prix bas, volume élevé

## Limites
- Données observationnelles
- Hypothèse d’élasticité constante
- Faible nombre de points

## Technologies
- Python
- pandas
- scikit-learn
- matplotlib
